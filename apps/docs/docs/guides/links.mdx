title: Links
description: Hyperlinks on text, shapes, pictures and table cells, and links from one slide to another.
---

Every object that can hold a link takes `href`: text runs (`<Run>`), `<Shape>`, `<Image>`, `<TableRow>` and `<TableCell>`. `href` takes a web address, or `{ slide, tooltip? }` to jump to another slide of the same deck.

```vue LinksDeck.vue
<script setup lang="ts">
import { Presentation, Run, Shape, Slide, Table, TableCell, TableRow, Text } from 'vue-pptx-document'
</script>

<template>
  <Presentation title="Links">
    <Slide title="Start">
      <Text :x="0.5" :y="0.5" :w="9" :h="0.6">
        See <Run :href="{ slide: 'Pricing' }">the prices</Run> or <Run href="https://vuejs.org">Vue</Run>.
      </Text>
      <Shape type="roundRect" :x="0.5" :y="1.5" :w="3" :h="1" fill="#f35815" :href="{ slide: 2, tooltip: 'Prices' }" />
    </Slide>
    <Slide title="Pricing">
      <Table :x="0.5" :y="1.2" :w="6">
        <TableRow href="https://vuejs.org/guide/">
          <TableCell>Vue guide</TableCell>
          <TableCell href="https://vuejs.org/api/">Own link</TableCell>
        </TableRow>
      </Table>
    </Slide>
  </Presentation>
</template>
```

## Web addresses

`href="https://…"` is a shorthand for `hyperlink: { url }`. A `hyperlink` prop wins over `href` when both are set, which is how to give a link a tooltip:

```vue
<Image src="/logo.png" :x="0.5" :y="0.5" :w="1" :h="1" :hyperlink="{ url: 'https://vuejs.org', tooltip: 'Vue' }" />
```

## Slides

A slide link takes the slide's number, counted from 1, or the `title` or `section` of a slide:

```vue
<Run :href="{ slide: 3 }">the third slide</Run>
<Run :href="{ slide: 'Pricing', tooltip: 'Go to the prices' }">the prices</Run>
```

A name is looked up as a `title` first, then as a `section`, and the first match wins. Names are resolved after every slide of the deck exists, so a link can point forward. Give slides unique titles if you link to them by name.

A link that matches no slide, a number past the last slide or a name nothing has, is dropped with an `unresolved-link` warning on the slide it's on. The object is still written, without the link.

## Table rows and cells

An `href` on `<TableRow>` links every cell in that row that doesn't set its own `href`. A cell with its own link keeps it.

## Preview

The preview makes web, mail and phone links clickable, as anchors. It doesn't follow slide links: a slide link appears as its text.

## Importing

The [importer](/guides/import) reads a jump to another slide back as `href` with `{ slide }`, and a web link as `href` with the address, so a deck with links round-trips with them intact.
