Every type here is exported from `vue-pptx-document` as a type-only export:

```ts
import type { ChartSeries, ComboChart, DeckModel, FlexStyle, Length, TextProps } from 'vue-pptx-document'
```

## Length

```ts
type Length = number | `${number}` | `${number}${'in' | 'cm' | 'mm' | 'pt' | 'px' | 'emu' | '%'}`
```

A number is inches. See [Units](/guides/layout#units).

## Color

```ts
type Color = string
```

A CSS hex color (`#f35815`, `#fff`), a known CSS name (`white`) or a theme slot (`accent1`). See [Colors](/guides/text#colors).

## FlexStyle

The `style` prop of every object, read inside a `<View>` or a `<Slide layout="flex">`. Lengths are numbers in inches, strings with a unit, or percentages.

| key                                                                                                             | values                                                                                         |
| --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `display`                                                                                                       | `flex`, `none`                                                                                 |
| `position`                                                                                                      | `relative`, `absolute`                                                                         |
| `flexDirection`                                                                                                 | `row`, `column`, `row-reverse`, `column-reverse`                                               |
| `flexWrap`                                                                                                      | `nowrap`, `wrap`, `wrap-reverse`                                                               |
| `flex`, `flexGrow`, `flexShrink`                                                                                | numbers                                                                                        |
| `flexBasis`                                                                                                     | a length                                                                                       |
| `justifyContent`                                                                                                | `flex-start`, `center`, `flex-end`, `space-between`, `space-around`, `space-evenly`            |
| `alignItems`, `alignSelf`                                                                                       | `flex-start`, `center`, `flex-end`, `stretch`, `baseline` (and `auto` for `alignSelf`)         |
| `alignContent`                                                                                                  | `flex-start`, `center`, `flex-end`, `stretch`, `space-between`, `space-around`, `space-evenly` |
| `width`, `height`, `minWidth`, `minHeight`, `maxWidth`, `maxHeight`                                             | lengths; `width` and `height` also `auto`                                                      |
| `aspectRatio`                                                                                                   | a number                                                                                       |
| `gap`, `rowGap`, `columnGap`                                                                                    | lengths                                                                                        |
| `padding`, `paddingTop`, `paddingRight`, `paddingBottom`, `paddingLeft`, `paddingHorizontal`, `paddingVertical` | lengths                                                                                        |
| `margin`, `marginTop`, `marginRight`, `marginBottom`, `marginLeft`, `marginHorizontal`, `marginVertical`        | lengths, or `auto`                                                                             |
| `top`, `right`, `bottom`, `left`                                                                                | lengths, for `position: 'absolute'`                                                            |

| ------------------- | ------------------------------------------------------ |
| `PresentationProps` | `<Presentation>`                                       |
| `SlideProps`        | `<Slide>`                                              |
| `MasterProps`       | `<Master>`                                             |
| `PlaceholderProps`  | `<Placeholder>`                                        |

| `TextProps`         | `<Text>`                                               |
| `ParagraphProps`    | `<Paragraph>`                                          |
| `RunProps`          | `<Run>`                                                |
| `ShapeProps`        | `<Shape>`                                              |
| `ImageProps`        | `<Image>`                                              |
| `TableProps`        | `<Table>`                                              |
| `TableCellProps`    | `<TableRow>` and `<TableCell>`                         |
| `ChartProps`        | `<Chart>`                                              |
| `MediaProps`        | `<Media>`                                              |

Supporting types:

| type                 |                                                                           |
| -------------------- | ------------------------------------------------------------------------- |
| `FillProp`           | `Color \| PptxGenJS.ShapeFillProps`                                       |
| `LineProp`           | `Color \| PptxGenJS.ShapeLineProps`                                       |

| `TableCellValue`     | `string \| number \| boolean \| null \| undefined \| PptxGenJS.TableCell` |
| `ChartType`          | `ChartName`, in any case                                                  |

## Chart data

```ts
type ChartName = 'area' | 'bar' | 'bar3D' | 'bubble' | 'bubble3D' | 'doughnut' | 'line' | 'pie' | 'radar' | 'scatter'

interface ChartSeries {
  name?: string
  labels?: string[]
  values?: number[]
  /** Bubble sizes, for bubble charts. */
  sizes?: number[]
}

interface ComboChart {
  type: ChartName
  data: ChartSeries[]
  options?: PptxGenJS.IChartOpts
}
```

## DeckModel

The resolved presentation. The writer hands it to PptxGenJS, the preview draws it, and the importer produces one. Every frame is final and in inches, and options are in PptxGenJS's own shape (colors as six-digit hex, `margin` in PptxGenJS's order).

```ts
interface DeckModel {
  layout: DeckLayout
  meta: DeckMeta
  rtl?: boolean
  theme?: PptxGenJS.ThemeProps
  masters: MasterModel[]
  slides: SlideModel[]
}

interface DeckLayout {
  /** A PptxGenJS layout name, such as LAYOUT_16x9, or CUSTOM. */
  name: string
  width: number
  height: number
}

interface DeckMeta {
  title?: string
  author?: string
  company?: string
  subject?: string
  revision?: string
}

interface SlideModel {
  background?: Background
  color?: string
  hidden?: boolean
  master?: string
  section?: string
  notes?: string
  slideNumber?: PptxGenJS.SlideNumberProps
  objects: SlideObject[]
}

interface MasterModel {
  name: string
  background?: Background
  margin?: PptxGenJS.Margin
  slideNumber?: PptxGenJS.SlideNumberProps
  objects: SlideObject[]
}

interface Background {
  color?: string
  transparency?: number
  /** An image URL or data URI. */
  src?: string
}

interface Frame {
  x: number
  y: number
  w: number
  h: number
}
```

### SlideObject

One drawable object, discriminated by `kind` (`SlideObjectKind`):

```ts
type SlideObject =
  | { kind: 'text'; frame: Frame; runs: TextRun[]; options: PptxGenJS.TextPropsOptions }
  | { kind: 'shape'; frame: Frame; shape: string; options: PptxGenJS.ShapeProps }
  | { kind: 'image'; frame: Frame; src: string; options: PptxGenJS.ImageProps }
  | { kind: 'table'; frame: Frame; rows: TableCellModel[][]; options: PptxGenJS.TableProps }
  | { kind: 'chart'; frame: Frame; type: ChartName | ComboChart[]; data: ChartSeries[]; options: PptxGenJS.IChartOpts }
  | { kind: 'media'; frame: Frame; options: PptxGenJS.MediaProps }
  | { kind: 'placeholder'; frame: Frame; name: string; text?: string; options: PptxGenJS.PlaceholderProps }

interface TextRun {
  text: string
  options?: PptxGenJS.TextPropsOptions
}

type TableCellModel = { text?: string | TextRun[]; options?: PptxGenJS.TableCellProps }
```

## PptxWarning

```ts
interface PptxWarning {
  code: WarningCode
  message: string
  slide?: number // 1-based
  object?: string // such as '<Image>'
}

type WarningCode =
  | 'dropped-text'
  | 'misplaced-object'
  | 'unknown-master'
  | 'master-object-dropped'
  | 'missing-src'
  | 'unknown-color'
  | 'unknown-prop'

interface DiagnosticOptions {
  onWarn?: (warning: PptxWarning) => void
  strict?: boolean
}
```

What each code means: [Troubleshooting](/guides/troubleshooting#warnings-codes-and-strict-mode).
